# Buenos Días Café x Por La Noche

## What is this?
Buenos Días Café x Por La Noche is a multi-page restaurant concept website built around the idea of a space that changes throughout the day. During the morning and afternoon, the restaurant operates as a café focused on coffee, breakfast, and pastries. In the evening, the space transitions into a warmer dinner experience with a different atmosphere and menu.

## Why does it exist?
This project was created to explore how a single website can communicate two distinct experiences while still feeling visually consistent and easy to navigate. The goal was to build a polished, realistic restaurant website that demonstrates front-end web development skills, responsive design, and iterative improvement throughout the semester.

## What tools did I use?
- HTML for page structure and content
- CSS for layout, styling, responsiveness, and visual consistency
- JavaScript for interactive features and navigation behavior
- VS Code as the primary development environment
- Git and GitHub for version control
- GitHub Pages for deployment

I chose these tools because they allowed me to build the site from scratch while maintaining full control over the structure, styling, and user experience.

## What changed from Project 01 to Project 02?
From Project 01 to Project 02, I focused on improving usability, layout consistency, and the overall user experience. One of the biggest additions was the “Now Serving” feature on the homepage, which updates dynamically depending on whether the café is currently serving the day menu, the night menu, or is closed.

I also redesigned the contact page into a more complete “Plan Your Visit” experience by combining restaurant information with an embedded map in a more responsive layout. Throughout the project, I refined spacing, navigation, responsiveness, and visual consistency across pages. These changes helped the site feel more polished and more representative of a real restaurant website rather than an early prototype.
